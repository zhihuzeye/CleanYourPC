项目名称：CleanYourPC
一、项目背景
我计划开发一个开源的 Windows 系统清理工具，项目名称为 CleanYourPC。
请参考 GitHub 上的开源项目 CleanYourTV，研究其项目架构、实现方式、自动化程度、用户交互方式及适合借鉴的设计理念。
注意：参考 CleanYourTV 的设计思路即可，不要直接假设其代码结构、技术栈或功能实现方式。如果需要复用其代码，必须先确认开源协议兼容性，并遵守相关许可要求。
你的任务不是简单地给我提供代码示例，而是实际完成一个能够运行、能够执行清理操作、能够持续迭代的 Windows 开源项目。
重要背景
你之前已经帮助我清理过 Windows 电脑。
请优先回顾我们之前的聊天记录，重点查找以下信息：

1. 之前发现的 Windows 锁屏广告、弹窗广告和软件推广。
2. 之前排查过的输入法广告、WPS 广告及其他软件广告。
3. 之前发现的推广软件、捆绑软件及不需要的软件。
4. 之前执行过的注册表修改、计划任务处理、启动项清理、软件卸载等操作。
5. 之前使用过的 PowerShell 命令、系统工具和其他有效解决方案。
6. 之前遇到的问题、失败的操作以及需要避免的误操作。
   如果能够找到历史操作记录，请提炼出可靠的解决方案，并将其转化为 CleanYourPC 的自动化清理功能。
   如果无法获取历史记录，不要编造之前执行过的操作。请明确说明缺少哪些信息，再通过实际检查和可靠资料补充。
   二、项目核心目标
   开发一个面向普通 Windows 用户的自动化清理工具。
   核心理念：
   打开软件 → 点击一次开始清理 → 自动检查问题 → 自动处理安全且明确的清理项 → 展示清理结果。
   尽可能减少用户的手动操作，不要求用户自己查找注册表、输入命令、定位广告文件或逐个关闭广告。
   软件应优先支持 Windows 10 和 Windows 11。
   界面语言使用简体中文。
   项目采用开源方式发布，代码结构清晰，便于后续维护和扩展。
   三、需要解决的问题
7. Windows 锁屏广告
   检查并处理以下问题：

- Windows 锁屏界面的推荐内容和推广信息。
- Windows 聚焦、提示、建议及其他可能出现的推广内容。
- 开始菜单、通知中心中的应用推广和建议内容。
- Windows 设置中可以关闭的广告、个性化推荐和营销提示。
- 其他能够通过受支持的系统设置安全关闭的推广内容。
  要求：
- 优先使用 Windows 官方支持的配置方式。
- 能够识别当前系统版本及对应配置是否适用。
- 区分广告关闭、推荐关闭与系统核心功能关闭。
- 不要为了关闭广告而破坏锁屏、登录、通知等正常功能。

2. 软件弹窗广告
   重点排查：

- 开机自动弹出的推广窗口。
- 桌面右下角的软件推广通知。
- 软件退出后仍然出现的推广窗口。
- 通过计划任务定时弹出的广告。
- 随系统启动的广告程序。
- 浏览器通知权限导致的广告弹窗。
- 后台常驻程序引起的推广内容。
- 其他能够通过合法、安全方式识别和处理的广告来源。
  不要只针对某个广告窗口执行关闭操作，而应尽量识别其来源，处理对应的软件设置、启动项或计划任务。

3. 输入法广告
   针对当前电脑实际安装的输入法进行识别，例如：

- 搜狗输入法。
- 百度输入法。
- 讯飞输入法。
- QQ 输入法。
- 微软拼音及其他输入法。
  检查并处理：
- 输入法皮肤、新闻、热点及推广弹窗。
- 资讯推荐和营销通知。
- 不必要的自动更新推广。
- 非必要的开机启动程序。
- 输入法自带的广告推广组件。
  要求：
- 优先通过输入法自身设置关闭广告。
- 对不同版本建立独立的适配规则。
- 不得误删输入法核心文件。
- 不得导致输入法无法使用。
- 对无法安全关闭的项目，明确告知用户原因。

4. WPS 广告
   识别当前安装的 WPS Office 版本，并检查：

- WPS 首页的广告和推广内容。
- 新闻、热点和资讯推荐。
- 弹出的会员营销窗口。
- 非必要的推广通知。
- 不必要的开机启动组件。
- 与广告展示有关的非核心常驻程序。
- 其他能够通过官方设置或可靠配置方式关闭的推广功能。
  要求：
- 优先采用 WPS 官方提供的广告关闭设置。
- 不要破坏文档编辑、表格、演示、PDF 等正常功能。
- 不要直接删除整个 WPS 安装目录。
- 不要随意修改核心程序文件。
- 对不同版本采用适配规则，并记录操作结果。

5. 360、腾讯电脑管家等软件的卸载
   重点识别以下软件：

- 360 安全卫士。
- 360 杀毒。
- 腾讯电脑管家。
- 其他用户明确不需要的电脑管家、优化工具和推广软件。
  实现以下能力：

1. 自动扫描当前安装的软件。
2. 识别软件名称、版本、安装路径和卸载入口。
3. 检查软件是否存在官方卸载程序。
4. 对明确指定的软件，调用其官方卸载程序或 Windows 支持的卸载机制。
5. 在卸载前检查是否存在关联组件、驱动或其他依赖。
6. 卸载后检查残留的启动项、计划任务、服务和非必要文件。
7. 仅在确认安全且属于该软件的情况下，清理残留项目。
   注意：

- 不得把 Windows Defender、Windows 防火墙或系统安全更新误判为恶意或推广软件。
- 不得把所有安全软件都认定为必须卸载。
- 如果用户仍然依赖某个软件提供安全防护，应明确提醒。
- 不得使用强制删除目录、直接杀死关键进程等方式替代正常卸载。
- 对受保护的服务、驱动、过滤器或存在依赖关系的组件，应采用官方卸载方式。
- 卸载操作必须明确告知用户软件名称，并提供可撤销或恢复的合理方案。

6. 捆绑软件和推广软件识别
   建立软件风险识别机制，重点关注：

- 用户不知情安装的软件。
- 随其他软件捆绑安装的程序。
- 无明显用途且频繁推广的软件。
- 具有异常启动行为的软件。
- 可疑的计划任务和常驻进程。
- 可疑的浏览器扩展和通知权限。
- 伪装成系统工具的推广软件。
- 反复安装其他软件的程序。
  识别时综合考虑：
- 软件名称、发布者、数字签名。
- 安装路径、安装来源和卸载信息。
- 文件哈希及可信威胁情报。
- 启动行为、计划任务和服务关联。
- 用户反馈和可验证的风险规则。
  不要只通过软件名称判断是否属于推广捆绑软件。
  对于不能确定的程序，列入待确认列表，不要直接删除。
  四、一键清理工作流
  请将核心流程设计为以下阶段。
  阶段一：系统扫描
  自动收集：
- Windows 版本及系统配置。
- 已安装软件及卸载信息。
- 当前输入法及其版本。
- WPS 版本和相关组件。
- 已知软件广告配置。
- 开机启动项。
- 计划任务。
- 与目标软件有关的服务和后台程序。
- 浏览器通知权限及可疑扩展。
- 可以安全处理的系统推广配置。
- 其他与本项目功能直接相关的系统信息。
  扫描阶段默认不修改系统。
  阶段二：风险分析
  根据扫描结果，将问题分为四类：
  A. 可以自动处理的安全项目。
  例如，明确对应广告的官方设置，或者可以安全关闭的 Windows 推广选项。
  B. 需要管理员权限的项目。
  例如，需要提升权限才能修改的系统设置。
  C. 需要用户确认的项目。
  例如，卸载 360、腾讯电脑管家、删除不确定的软件残留。
  D. 高风险或无法确认的项目。
  例如，无法确认归属的服务、驱动、计划任务及系统关键组件。
  阶段三：自动执行
  点击一次清理后：

1. 执行安全的广告关闭操作。
2. 关闭已确认的推广通知和推荐配置。
3. 根据适配规则处理输入法和 WPS 广告。
4. 处理已确认可以安全禁用的广告启动项。
5. 对需要卸载的软件，执行经过授权的卸载流程。
6. 对需要用户确认的操作，暂停相应项目并请求确认。
7. 对执行失败的项目记录错误原因。
8. 不影响其他独立安全项目继续处理。
   在不影响系统安全的前提下，尽可能减少重复确认。
   阶段四：清理结果
   展示清理报告，包括：

- 扫描项目数量。
- 发现的问题数量。
- 成功处理的项目数量。
- 失败的项目数量。
- 需要用户确认的项目。
- 实际关闭了哪些广告。
- 卸载了哪些软件。
- 修改了哪些系统设置。
- 哪些操作需要重启。
- 哪些项目无法自动处理及原因。
  报告应能够导出为 JSON 或文本文件。
  五、自动化与安全要求
  这是项目的核心要求。

1. 一键操作
   普通用户不需要了解 PowerShell、注册表或 Windows 内部机制。
   主界面只需要突出：

- 开始扫描。
- 一键清理。
- 清理报告。
- 恢复设置。
- 设置与日志。
  可以将扫描和清理合并为一个主要操作，但必须在执行前完成必要的风险检查。

2. 权限管理

- 普通扫描尽量不需要管理员权限。
- 只有确实需要管理员权限的操作才请求提权。
- 不要要求用户长期以管理员身份运行整个程序。
- 对管理员操作明确显示原因和具体影响。
- 不要绕过 Windows 的权限和安全保护机制。

3. 操作备份与恢复
   在修改系统设置前，尽可能保存原始状态。
   需要支持：

- 记录修改前的配置值。
- 记录修改后的配置值。
- 记录执行时间和操作结果。
- 恢复本工具修改过的系统设置。
- 清理前后配置对比。
- 对无法可靠恢复的操作提前告知用户。
  恢复功能不得承诺能够恢复已卸载软件的所有数据。

4. 系统安全
   禁止以下实现方式：

- 为追求一键清理而批量删除未知文件。
- 未经确认强制卸载用户的软件。
- 禁用 Windows Defender、防火墙或系统安全更新。
- 删除未知服务、未知驱动或系统关键文件。
- 为了关闭广告而破坏核心应用功能。
- 绕过软件自我保护机制强行删除文件。
- 通过未经验证的脚本批量修改注册表。
- 自动执行来源不明的远程脚本。
- 将不确定的软件直接认定为恶意程序。
  所有修改必须具备明确的操作目标、适用条件和失败处理机制。

- Windows 官方卸载机制。
- 必要时使用轻量级桌面 UI 框架。
  如果采用 Electron、Tauri、C#/.NET 或其他技术栈，请说明选择理由，并权衡：
- 安装包体积。
- 启动速度。
- 系统管理能力。
- 管理员权限处理。
- Windows 10/11 兼容性。

  建议拆分为：
- 系统信息扫描模块。
- 广告识别与配置模块。
- 软件卸载模块。
- 启动项与计划任务管理模块。
- 风险评估模块。
- 备份与恢复模块。
- 清理执行引擎。
- 日志与报告模块。
- 图形界面模块。
  模块名称可以根据实际技术栈调整，不要求机械照搬。
  七、规则引擎
  广告和软件版本会持续变化，不能把所有逻辑写死在一个大型脚本中。
  请设计可维护的规则机制，至少包含：
- 规则 ID。
- 规则名称。
- 适用系统版本。
- 适用软件及版本范围。
- 检测方式。
- 处理方式。
- 风险等级。
- 所需权限。
- 是否需要用户确认。
- 是否支持恢复。
- 规则来源及验证记录。
- 执行成功和失败的判断条件。
  规则应能够单独测试、停用和更新。
  未知规则默认不执行破坏性操作。

6. 已安装及未安装腾讯电脑管家的情况。

10. 备份与恢复是否有效。
11. 重复执行清理是否产生副作用。
12. 是否会误删正常软件和系统组件。
    优先使用 Windows 虚拟机进行测试。
    不得为了验证清理效果而直接破坏真实电脑的系统环境。
